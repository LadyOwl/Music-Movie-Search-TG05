# 🎵🎬 Music-Movie-Search-TG05

Telegram-бот для поиска музыки и фильмов. Бот помогает находить информацию об исполнителях, треках и фильмах прямо в Telegram с красивым оформлением и постерами.

## ✨ Возможности

### 🎵 Поиск музыки
- Поиск исполнителей с биографией и тегами
- Поиск треков с информацией о длительности и количестве прослушиваний
- Получение фотографий исполнителей
- Данные из **Last.fm API**

### 🎬 Поиск фильмов
- Поиск фильмов с постерами
- Информация о рейтинге, годе выпуска и описании
- Ссылки на TMDB и IMDb
- Данные из **TMDB API**

### 🤖 Удобный интерфейс
- Интерактивные кнопки для выбора режима поиска
- Команды для быстрого доступа (`/start`, `/movie`, `/help`)
- Понятные сообщения с форматированием

## 🛠️ Технологии

- **Python 3.8+** — основной язык
- **aiogram 3.x** — библиотека для создания Telegram-ботов
- **aiohttp** — асинхронные HTTP-запросы к API
- **asyncio** — асинхронное программирование
- **Last.fm API** — источник данных о музыке
- **TMDB API** — источник данных о фильмах

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/LadyOwl/Music-Movie-Search-TG05.git
cd Music-Movie-Search-TG05
```

### 2. Создайте виртуальное окружение

```bash
# Для Windows
python -m venv venv
venv\Scripts\activate

# Для macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Получите API-ключи

#### Telegram Bot Token
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота

#### Last.fm API Key
1. Зарегистрируйтесь на [Last.fm](https://www.last.fm/)
2. Получите API-ключ на странице [API accounts](https://www.last.fm/api/account/create)

#### TMDB API Key
1. Зарегистрируйтесь на [TMDB](https://www.themoviedb.org/)
2. Перейдите в настройки аккаунта → API → создайте новый ключ

### 5. Создайте файл конфигурации

Создайте файл `config.py` в корне проекта:

```python
# config.py
BOT_TOKEN = "ваш_telegram_bot_token"
LASTFM_API_KEY = "ваш_lastfm_api_key"
TMDB_API_KEY = "ваш_tmdb_api_key"
```

⚠️ **Важно:** Не добавляйте файл `config.py` в Git! Добавьте его в `.gitignore`.

### 6. Запустите бота

```bash
python main.py
```

Вы должны увидеть сообщение: `🤖 Бот запущен...`

## 📱 Использование

### Команды бота

- `/start` — главное меню с кнопками выбора режима
- `/movie <название>` — быстрый поиск фильма (например: `/movie Интерстеллар`)
- `/help` — справка по командам

### Режимы поиска

1. **Поиск музыки**: нажмите кнопку "🎵 Найти музыку" и отправьте название исполнителя или трека
2. **Поиск фильмов**: нажмите кнопку "🎬 Найти фильм" и отправьте название фильма
